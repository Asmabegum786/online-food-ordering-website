🍔 Online Food Ordering Website
📌 Project Description

The Online Food Ordering Website is a simple and user-friendly web application that allows customers to browse food items, view prices, add items to a shopping cart, and place orders online.

This project is developed using HTML, CSS, and JavaScript. It is designed as a beginner-friendly web development project that can be run directly using VS Code Live Server.

🎯 Objectives

To create a simple online food ordering platform.

To allow users to browse different food items.

To provide food prices and descriptions.

To allow users to add food items to a shopping cart.

To calculate the total order amount.

To provide a simple order placement feature.

To create a responsive and attractive website.

🛠️ Technologies Used

HTML5 – Website structure

CSS3 – Website design and styling

JavaScript – Interactive features

VS Code – Development environment

Live Server – Running the website locally

✨ Features
Home Page

Provides an introduction to the website with navigation links and an "Order Now" button.

Food Menu

Displays different food items with:

Food name

Description

Price

Add to Cart button

Shopping Cart

Users can:

Add food items

View selected items

View the total price

Place an order

Contact Section

Users can enter their name, email, and message.

Responsive Design

The website is designed to work on both desktop and mobile screens.

🚀 How to Run the Project
Step 1

Download or copy the project files to your computer.

Step 2

Open the project folder in Visual Studio Code.

Step 3

Make sure the following files are present:

index.html
style.css
script.js
README.md

Step 4

Open index.html in VS Code.

Step 5

Right-click on index.html and select:

Open with Live Server

The website will open in your browser.
